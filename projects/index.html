Phi Thuyền (game)

Game bắn phi thuyền trên canvas với hệ thống kỹ năng, kinh nghiệm và nâng cấp — dự án lập trình web đầu tiên.

GameCanvas
ChơiNhận xét code

Cách mình làm: đúng trước, đẹp sau

  1. Lõi tách khỏi giao diện. Phần vật lý (orbit.js, labs-core.js) là JavaScript thuần chạy được trong Node để kiểm thử.
  2. Kiểm với giá trị tham chiếu. v₁ = 7,91 km/s, bán kính địa tĩnh 42 164 km, Hohmann Trái Đất → Sao Hỏa 259 ngày… đều được kiểm tự động.
  3. Đáp án được tính lại độc lập. Script đọc ngân hàng câu hỏi, tính lại từng đáp số và kiểm rằng không phương án nhiễu nào trùng đáp án đúng.
  4. Kiểm thử trên trình duyệt thật. Playwright mở từng trang, bấm như người dùng, chụp ảnh, kiểm tra điện thoại 375 px và console sạch lỗi.
  5. Trung thực về giới hạn. Mô hình đơn giản hóa và thông tin chưa chắc đều được ghi rõ là "cần xác minh".

Công nghệ: HTML/CSS/JavaScript thuần (không framework, không bước build), Canvas 2D, KaTeX (đặt sẵn offline), Node.js + Playwright cho kiểm thử. Chạy offline bằng cách mở tệp; đưa lên GitHub Pages là dùng được.
